【账户安全指南】

一、账户安全设置
1. 登录密码：8-20位，需包含字母、数字和特殊字符。
2. 交易密码：6位纯数字，不可与登录密码相同。
3. 手机绑定：一个手机号仅可绑定一个账户，变更需身份验证。
4. 双重验证：建议开启短信验证码+指纹/面容双重验证。

二、账户异常处理
1. 账户被锁定：连续输错密码5次，账户锁定30分钟。可通过手机验证码解锁。
2. 可疑交易：系统检测到异常交易会自动冻结账户并短信通知。
3. 账户被盗：立即拨打客服热线冻结账户，携带身份证到柜台办理解冻。
4. 信息泄露：立即修改密码，检查账户交易记录，必要时报警。

三、防诈骗提醒
1. 官方客服不会索要验证码、密码或要求转账。
2. 不要点击陌生链接或扫描不明二维码。
3. 警惕"高收益、零风险"的投资诱惑。
4. 不要向陌生人透露银行卡号、身份证号等敏感信息。
5. 收到可疑电话或短信，请拨打官方客服核实。

四、资金安全保障
1. 资金存管：客户资金由银行第三方存管，与平台自有资金隔离。
2. 保险保障：存款保险制度保障，单人单行50万元以内全额赔付。
3. 交易限额：可设置单日交易限额、单笔交易限额。
4. 实时监控：7×24小时风控系统实时监控异常交易。

五、常见问题
Q: 如何修改绑定手机号？
A: 通过APP「设置-安全中心-手机号变更」，需验证原手机号+身份证+人脸识别。

Q: 账户被冻结怎么办？
A: 拨打客服热线，提供身份信息，客服会告知冻结原因并指导解冻流程。

Q: 发现账户有不明交易怎么办？
A: 立即冻结账户，保存交易记录截图，联系客服核实并报警处理。

Q: 如何设置交易限额？
A: 通过APP「设置-安全中心-交易限额」，可设置单笔和单日限额。
